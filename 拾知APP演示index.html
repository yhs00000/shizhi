Features

治「收藏了从不回看」这件事

六个功能，围绕一个目标：让刷到的知识真正沉淀下来，而不是堆在收藏夹里吃灰。

📝

一键解析成卡

粘贴 B 站 / YouTube / 文件直链，AI 提炼「一句话精华 + 核心要点 + 智能标签 + 回看建议」。

🌳

知识树自动归类

按领域自动生长知识图谱，跨领域共享标签自动连线，把零散卡片织成一张网。

🔕

20% 精选推送

每晚定点只把当天最重要的 20% 推到主屏，其余内容零打扰，杜绝信息焦虑。

🔗

短链展开 + 智能去重

自动展开分享短链、归一不同链接形态，同一视频只收一次，省 API 额度。

🎛️

三种制卡模式

单次智能卡 / 简洁卡 / 两次精制卡，可自由切换对比效果，兼顾速度与打磨。

🌙

打卡复盘

完成「晚间复习」自动打卡，月历记录成长轨迹，把复习变成看得见的习惯。

Architecture

云端 API + 本地存储，无需自建后端

AI 解析走 BibiGPT 开放 API，数据存手机本地，打包成独立 APK 即可离线日常使用。

⚙️ 架构

📱
React Native 客户端Expo + TypeScript，本地状态管理
🤖
BibiGPT 开放 APIAI 解析 / 字幕抓取 / 额度查询
💾
AsyncStorage 本地存储知识卡片、设置、打卡记录
🔔
本地定时通知每晚 20% 精选，无需服务器推送
